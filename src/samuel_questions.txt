Très bonne question — et là, la réponse est nuancée selon le site.
Je te fais un état des lieux clair, exploitable et honnête 👇

🟢 Oracle’s Elixir
❌ Pas d’API REST officielle

Pas d’endpoint documenté

Pas d’accès programmatique “clé/API key”

✅ MAIS : exports CSV officiels

👉 C’est volontairement la voie recommandée

Oracle’s Elixir met à disposition :

des CSV propres

maintenus

stables

par :

ligue

split

patch

joueur

équipe

Exemples de données :

gold diff @10 / @15

cs diff

XP diff

KDA

durée de game

side (blue/red)

champion

rôle

➡️ C’est l’équivalent d’une API… en fichiers

💡 En pratique :

tu télécharges périodiquement les CSV

tu les importes en DB

tu fais tes requêtes dessus

👉 C’est LA solution la plus propre et la plus utilisée en data LoL pro

🟡 Gol.gg
❌ Pas d’API officielle
⚠️ API interne / scraping possible

Données accessibles via le frontend

JSON parfois visibles dans les requêtes réseau

Pas documenté

Pas garanti

Risque de blocage

👉 Gol.gg est très bon pour :

consultation humaine

vérification rapide
👉 Moins bon pour :

pipeline data long terme
